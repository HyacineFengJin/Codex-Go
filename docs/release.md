# Codex Go 0.23.0 · 独立 CLI 更新

2026-11-20，公开预览版。本版整合 0.22.0 的 Codex CLI 0.171.0、GPT‑6.2 Sol / Astra 和应用更新检查，并支持单独安装或更新 Codex CLI APK。

- 主程序可用内置 CLI 启动。Android 安装独立 CLI 后，下次启动引擎会核对包签名、架构和版本，再切换到独立运行时。
- 更新独立包前先停止引擎，安装完成后重启。关闭「独立 CLI」或卸载独立包可切回内置。独立版本启动或握手失败时自动回退。
- 模型目录从当前运行的 CLI 获取。账号、历史、项目、草稿和队列继续由主程序管理。

Android 15 x86_64 模拟器通过内置 0.165.0 → 独立 0.171.0 的实际升级，主 APK 哈希保持相同，并验证历史 / 草稿恢复、新模型请求、工具执行、重启、卸载回退以及握手失败自动回退。147 项 JVM 测试和两种架构构建 / lint 通过。ARM64 APK 已核对签名与载荷，真机待验证。模型响应使用本机测试服务。

[GitHub Release](https://github.com/HyacineFengJin/Codex-Go/releases/tag/v0.23.0) · [验证记录](../artifacts/verification.json)

模型事件来自本机确定性测试服务，没有登录真实账号、调用真实模型或操作用户手机。ARM64 / OEM、真实账号与长期压力仍待验证。公开 APK 不包含 Google CLI；Antigravity 仍为源码中的可选实验适配，不能将 ACP 夹具通过视为 Google 登录 / 订阅可用性验证。

# Codex Go 0.17.0

构建：2026-11-10；首个公开预览版发布：2026-11-11。区分观察、预读与操作提示，加入中英文界面和应用语言设置。

- 顶部提示改为灵动岛风格的深色扁平胶囊：Codex 图标与单行状态，去掉蓝色渐变、描边和外发光；自适应内容宽度与字号，避开状态栏和挖孔。屏幕边缘蓝色提示保留。
- 实时观察显示 “Codex is viewing your screen”，结构预读显示 “Codex is reading your screen”，点击 / 滑动 / 输入等动作显示 “Codex is using your phone”。重叠时优先显示实际操作；仅缓存图片、模型思考与纯 Shell 工作不点亮。
- 界面、通知、配对窗、悬浮对话和服务名称使用 Android 字符串资源。默认跟随系统，也可在「设置 → 语言」选择 English / 简体中文；Android 13 以上与系统的应用语言设置同步，Android 11 / 12 保存应用内选择并重建界面。
- 切换语言只更新界面与通知，不重启任务。用户输入、项目名、对话标题、模型回复与命令保持原文。大字号下语言入口自动改为两行，模型入口与快捷控制保留。
- 无障碍与无线调试仍可同时使用，不增加 AI 授权开关；实时观察图片与历史图片机制保持原有行为。
