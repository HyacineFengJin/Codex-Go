# 当前功能与后续优先级

2026-11-16，基于 Codex Go 0.21.0。DSH-Go 与 OpenMinis 的观察用于交互和架构取舍，当前代码与前端独立实现。

## 当前基础

本机 Codex、模型 / 思考选择、项目与草稿归属、系统分享、账户配置恢复、后台跨会话浏览、M3 Expressive / Bento 界面、悬浮聊天与通知回复均已实现。任务、审批和排队始终属于执行对话；浏览其他对话不会自动发送或切换执行目标。无障碍与无线调试继续互补并开。

0.8.0 已通过 62 项 JVM 测试与 13 组 Android 检查；0.9.0 增加四种 Shell 连接和配对小窗，当前验证范围以交付包旁的汇总为准。0.9.0 在 V2505A（Android 16 / ARM64）已完成有线 ADB 的 App 内 id 验证；0.12.1 已在该真机启动原生引擎并恢复多截图对话。完整 ChatGPT 登录流程、真实模型任务与长期后台仍需专项验收。详见 [当前版本](release.md) 与 [验证方法](testing.md)。

屏幕预读取实验已加入：当前提供无障碍 / WebView 语义、提示 / 错误 / 滑杆数值、窗口覆盖检查，并可通过当前 Codex 账号选用轻量图像模型辅助预读。它只返回事实，判断、操作与原图复核由主 Codex 完成。调用链已用本地夹具验证，下一步需要实际账号与代表性页面评估完整性、错误率和成本。手机内嵌推理与独立 OCR 仍未实现。完整 DOM 需独立浏览器连接能力。

0.13.0 已接入可选的旧图预览、持久原图引用与 MCP 按需重读，实际变换模型请求，实时观察保持原样。下一步验证真实账号、workspace routing、更多图片来源 / 文件 ID、容量与并发压力，并测量 token / 时间和误读率。原生 Codex 的内存与原始会话文件尚未裁剪。

## 后续顺序

1. **长内容与完整产物审阅**：Markdown 表格 / 列表 / 引用、代码高亮、长日志 / 长回复的完整入口与导出、大 diff 审阅及截断提示。长回复 / 长 diff 的完整入口、分页、搜索和导出已实现，64,000 字符客户端裁剪已移除；后续补更完整的排版和代码高亮。
2. **计划与上下文 / 用量状态**：持续更新的计划步骤、计划 / 执行入口、实际生效的执行策略、上下文 / 额度和压缩状态。逐项验证打包的 0.165.0 实际行为。
3. **会话 / 项目 / 文件管理**：正文搜索、置顶 / 分叉 / 导出、项目备份归档、文件重命名 / 移动 / 删除和仓库入口。
4. **Skills / MCP 与扩展管理**：Plugin API 1 与独立 APK 示例已实现。配置与作用范围、连接状态、认证 / 追问表单、修复后的保留。协议 schema 中存在定义，不代表客户端已经接入或 Android 已验证。

首个会话创建与附件导入并发、分享复制中进程死亡、复杂原生文件变更、原生扩展和不同厂商的悬浮窗 / 后台行为仍需专项验证。远程主机维持后排。

## 0.21.0：恢复与原生回归

补齐跨引擎草稿提交回执、原生默认工具裁剪适配，以及文件编辑器旋转恢复。使用完整原生模拟器包检查退出、主进程终止、强制停止、升级和设备重启后继续使用；不自动重放旧队列。实际结果与未覆盖范围见 [本轮自检](lifecycle-selfcheck.md)。Antigravity 仍是源码中的可选实验，公开包未包含 Google CLI；真实账号与真机兼容性优先于继续增加入口。
