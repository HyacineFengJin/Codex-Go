# 0.21.0 日常使用与恢复自检

2026-11-16。使用独占 Android 15 / x86_64 模拟器 `emulator-5570`，未连接或操作用户手机。公开交付为 ARM64 完整 APK；原生流程测试使用相同应用源码的完整 x86_64 APK，包含真实 Codex 0.165.0、PRoot、Python / Node / npm / Git。模型事件来自本机 Responses 测试服务和假 API key，没有真实账号登录或外部模型推理。

## 本轮修复

| 问题 | 修复与验证 |
| --- | --- |
| 分享 / 快速消息加入 Antigravity 草稿时仍写 Codex 偏好，重开后丢失或覆盖另一引擎草稿 | 按所选引擎提交目标草稿；通过生产 EngineService / 收件箱控制器实测，再重复冷开和切回 Codex，核对两边内容。 |
| 跨偏好提交时，目标已保存而收件箱清理前中断，重试可能重复追加 | 目标草稿与回执先一起提交，清理失败保留重试入口；分享路由绑定原引擎 / 项目 / 草稿。JVM 测试模拟提交失败及重新加载，确保不重复合并并保留之后的用户编辑。 |
| 文件编辑器旋转时关闭且丢失未保存内容，界面作用域也会取消正在保存的协程 | Activity ViewModel 保留缓冲与保存作业，只将路径写入小型保存状态。模拟器复现旧问题后，验证旋转、Home 返回、保存、外部冲突、显式放弃和冷开已保存文件。保存采用固定快照与原子替换。 |
| 原生默认工具输出裁剪从中间破坏屏幕 JSON，丢失可解析的原图引用 | 没有显式预算时为新建 / 恢复的 Codex 会话提供高于传输内存边界的输出预算；用户配置继续保留。完整原生历史图片流程验证结构、缩图、按需原图、重启、隔离和关闭回退。 |
| 恢复自身悬浮球后，原图缓存被误判为屏幕已变化 | 窗口清单排除自身的无障碍 / 应用悬浮层，仍保留真实应用窗口、第三方覆盖层和键盘。实际原生预读检查重复读取同帧原图，并继续验证真实页面变化会使旧图失效。 |
| 固定的部分旧依赖下载地址下架，无法从空缓存重建 | 增加公开 APK 哈希 / ABI / 输入清单校验的运行时复用入口。ARM64 的 177 项载荷与公开 0.17.0 逐字节相同；x86_64 测试锁更新已下架的 PRoot / Alpine 包。 |

`tool_output_token_limit` 的含义见 [官方配置参考](https://learn.chatgpt.com/docs/config-file/config-reference#tool_output_token_limit)。本版固定原生运行时的行为还通过实际请求验证，不仅依据当前文档推断。模型上下文和传输内存边界仍存在；不会预先分配所配置的预算。

## 恢复检查

| 场景 | 断言 |
| --- | --- |
| 旧版升级 | 从 v0.17.0 源码构建的旧界面包创建项目 / 草稿 / 文件，保留应用数据覆盖安装当前完整原生包，再冷开两次。公开 APK 另核对签名与 0.17.0 相同。 |
| Home / Back 后重开 | 通过普通任务恢复打开，保留未发送草稿和原生会话；任务运行时返回也不丢队列。 |
| 后台主进程 SIGKILL | 运行中的本地流被打断；草稿、项目、线程恢复，队列保持暂停，原来的未执行工具不会被重放。 |
| 强制停止后重开 | 已使用的引擎按保存偏好准备，草稿恢复，不自动发送。 |
| 设备重启后再打开 | 重启整个模拟器系统，重新映射测试端口后打开；假凭据、项目、线程、草稿、已写入文件和暂停队列都保留。随后明确发送一个新任务并收到回复。 |
| 跨引擎材料恢复 | 使用真实存储控制器加入分享和快速消息，冷开两次后切回 Codex，两个引擎的草稿互不覆盖。 |
| 编辑与界面重建 | 未保存编辑跨旋转 / 正常前后台切换；已保存文件跨冷开，冲突时保留外部修改。 |

精确 APK 哈希、检查组结果与测试范围保存在 [verification.json](../artifacts/verification.json)。测试脚本位于 `tools/check_*`，本轮新增 `check_lifecycle_recovery.py`、`check_upgrade_recovery.py`、`check_storage_recovery.py`、`check_editor_recovery.py` 和 `check_runtime_reuse.py`。

## 边界

- 文件编辑器尚未点击“保存”的缓冲不跨硬杀进程或系统重启持久化；聊天草稿会持续保存。正常关闭编辑器有放弃确认。
- 未验证 ARM64 真机 / OEM 的省电、后台、通知输入与系统覆盖层差异；没有操作用户手机。
- 未完成真实 ChatGPT / Google 登录、Luna 预读质量 / 成本测量、真实模型任务，以及真实 root / Shizuku 授权撤销回归。
- 公开 APK 不包含 Google CLI。Antigravity 的存储路径与 ACP 夹具测试不代表真实 Google 订阅任务已经可用。
- 未覆盖超长压力运行、分享复制中途进程死亡、更多来源 App 的分享提供器，以及无法从本机存储恢复的旧历史原图。

原创部分使用 MIT；第三方许可不变。公开包沿用的原生依赖源码材料与哈希随同一 Release 提供。
